# Open asks tracking

Maintain a concise list of unresolved user questions, decisions, and blocked
inputs for the current task.

## Workflow

1. Capture only questions or decisions that are necessary to complete the
   active request.
2. Mark each item as resolved, pending user input, blocked by evidence, or no
   longer needed.
3. Ask for user input only when there is a material decision or missing
   information that cannot be safely inferred.
4. Before completing the task, resolve every item or state why it remains open.

Do not treat an optional suggestion, a superseded request, or an already
answered question as open. This skill tracks asks only within the active
conversation; it does not automatically observe future turns.
